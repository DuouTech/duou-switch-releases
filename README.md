# Duou-Switch 下载与更新

本仓库仅分发 Windows x64 安装包、Tauri 更新签名和发布说明。源码在私有仓库维护。

当前处于自动更新验收阶段。testing 频道与预发布资产仅用于受控测试，尚未切换 stable 频道。请等待经过批准的稳定发布。

Duou v4.0.0 的自动更新在客户端中关闭，需要一次手动覆盖安装首个启用更新的版本。保留原安装范围和 .duou-switch 数据目录，之后可在软件内检查并确认安装签名更新。

基于 farion1231/cc-switch，遵守 MIT 许可并保留原作者版权。更新与 CC Switch 官方软件分别签名和分发。
